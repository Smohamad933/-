# آریا ERP — سیستم جامع مدیریت منابع سازمانی

سیستم ERP فارسی با رابط کاربری مدرن و واکنش‌گرا شامل:

## ماژول‌ها

### ۱. حسابداری مالی
- سیستم حسابداری چندسطحی (کل، معین، تفصیلی، شناور)
- صدور اسناد دستی و اتوماتیک
- مدیریت تنخواه‌گردان
- مدیریت چک و اوراق بهادار
- مغایرت‌گیری بانکی
- محاسبات مالیاتی و ارزش افزوده (ماده ۱۶۹)
- گزارش‌های مالی: ترازنامه، سود و زیان، گردش وجه نقد، تراز آزمایشی

### ۲. انبارداری و لجستیک
- مدیریت چند انبار
- شناسنامه کالا (SKU، بارکد، واحد اصلی/فرعی)
- کنترل موجودی و هشدارها
- روش‌های FIFO، LIFO، میانگین موزون
- اسناد انبار و انبارگردانی
- ردیابی سریال و بچ

### ۳. دارایی‌های ثابت
- شناسنامه اموال و پلاک‌کوبی
- محاسبه استهلاک (خط مستقیم، نزولی، کارکرد)
- تعمیر و نگهداری، بیمه، نقل‌وانتقال

### ۴. خرید، فروش و بازرگانی
- چرخه فروش (پیش‌فاکتور تا فاکتور)
- چرخه خرید (درخواست تا فاکتور)
- CRM پایه مشتریان و تامین‌کنندگان
- پورسانت بازاریابان

### ۵. امنیت و زیرساخت
- یکپارچگی لحظه‌ای (Real-time)
- سطوح دسترسی RBAC
- لاگ حسابرسی (Audit Trail)
- پشتیبان‌گیری و بازیابی
- **پنل مدیریت سفارشی‌سازی** — شخصی‌سازی ظاهر هر کاربر
- **مدیریت فونت** — افزودن فونت دلخواه از URL یا آپلود فایل

## اجرا

```bash
npm install
npm run dev
```

باز کردن [http://localhost:3000](http://localhost:3000)
